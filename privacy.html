1. Privasi Anda

Konverter Dunta memproses semua file (teks, Markdown, HTML, foto, dokumen Word) sepenuhnya di perangkat Anda. File tidak pernah diunggah ke server mana pun.

2. Data yang Kami Kumpulkan

Kami tidak mengumpulkan data pribadi apa pun. Tidak ada akun, tidak ada pelacakan, tidak ada analitik.

3. Iklan & Pihak Ketiga

Aplikasi ini tidak menampilkan iklan dan tidak membagikan data ke pihak ketiga.

4. Izin Aplikasi

Aplikasi hanya meminta izin yang diperlukan untuk memilih file dari perangkat dan menyimpan hasil PDF ke perangkat Anda.
